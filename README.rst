sale_delivery_date
==================

Tryton module to add manual delivery date to sale lines.

Installation
------------

See https://docs.tryton.org/ for installation instructions.

Configuration
-------------

No configuration required.

Usage
-----

Activate the module in your Tryton client. The field `manual_delivery_date` will appear on sale line forms.
